#Estacionamiento inteligente RFID
##Descripcion del proyecto
Este es un proyecto final de la materia **Informatica II**,correspondiente  a la carrera Ingenieria Electronica de la Universidad Tecnologia Nacional,Facultad Regional de Mendoza.
Consiste en un sistema de estacionamiento inteligente con capacidad para 4 vehiculos, que utiliza un arduino UNO para el manejo de los componentes electronicos,y Processing para manejar los ususarios mediante una interface grafica.
